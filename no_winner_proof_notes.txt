The idea is as follows:
	We define a node N to be *avoidable* if for all GP in Grandparents(N) one of the following is true:
		1. there exists a grandchild whose winning tuple is [0,x,x] or
		2. every parent of GP is itself avoidable.
		
First we make a straightforward observation:

Lemma: A node GP has a grandchild GC whose winning tuple is winner_GC = [0,x,x] if and only if the node itself has winning tuple winner_GP = [x,x,0].

Proof: This follows directly from how our winning tuples are defined. There exists a pair of moves that will result in the current player having no winning strategy, therefore, at the present node, the next next player has no guarantee of a win.
		
Remark: The goal is to avoid nodes where a single player has a winning strategy, i.e. winner_N = [1,x,x]. We can have two players collude to avoid such a node N if N is avoidable. Suppose Players A and B are trying to make Player C lose. If Player C is at node N, this is a problem. By moving back two layers and seeing if there is a different path that will result in a winner tuple of [0,x,x] we are checking to see if A and B can "take back" their moves that and instead move towards a game-state where the current player, who is now Player C, will be losing.

Moreover, the recursive nature of the definition is what will allow us to look back further than 2 moves in order to determine if a node is avoidable. Consider the following example.

Example: A node N in layer k has the property that all grandparents in layer k+2 have a grandchild with winning tuple [0,x,x] except a single node, call this node badGP in Grandparents(N). Notice that by our previous lemma winner_badGP = [x,x,1]. Then, hypothetically, if Player C was able to make a move that gives Player A the position described at node badGP, then no matter what two moves Player A and Player B make, every grandchild of node GP has winning tuple [1,x,x]. Hence, Player C is left with a winning move at layer k.

Players A and B must therefore avoid a situation where Player C (in layer k+3) can make a move resulting in badGP. Therefore, consider the set of parents Parents(badGP). These all have winning strategy [1,x,x]. If, for every P in Parents(badGP) and every GP^1 in Grandparents(P), there exists a grandchild GC^1 in Grandchildren(GP^1) such that winner_GC^1 = [0,x,x], then Players A and B could have always navigated to one of these grandchildren instead of the node P. Hence, Player C would never by able to make a move that gave Player A the position in node badGP.

Of course, there is no reason why all of the GP^1 in Grandparents(P) should have winner_GP^1 = [x,x,0]. But, if all GP^1 in Grandparents(P) with winner_GP^1 = [x,x,1] are nodes that are themselves avoidable, we can still classify P as avoidable. Hence, N is avoidable.

def filter_new_target(new_target: list) -> list:
    """
    From the new target set (list of (reduced_canonical, layer) tuples),
    remove nodes where A and B can apply the 'keep moves 1 mod 3' strategy:
      - has >= 2 positive gaps of size >= 3, AND
      - total remaining moves is not 1 mod 3

    Returns the filtered list (nodes that CANNOT be removed, i.e. still unavoidable).
    """
    filtered = []
    removed = 0
    for rc, layer in new_target:
        if has_two_plus_gaps(rc) and total_moves_from_reduced(rc) % 3 != 1:
            removed += 1
        else:
            filtered.append((rc, layer))
    print(f"  Strategy filter: removed {removed:,}, kept {len(filtered):,}")
    return filtered

Def: A *gap* is a tuple (n, +/-) where n is the length of the gap and +/- indicates the orientation of a gap. As shorthand we will simply write +n or -n

Def: A *gamestate* is a list of gaps. A *canonical gamestate* is a ordered gamestate using a lexicographic ordering (descending in both indices).

Def: A *reduced canonical gamestate* is a tuple (set of live-gaps, sum of moves left in inevitable-gaps) where a gap is considered inevitable if it is (<=2, +) or (<=4, -). The conversion between inevitable-gap length to moves left is given by (n,+) -> n, and (n,-) -> (n-1), since a -1 gap is unplayable, while a +1 gap is.

Proposition: Any position in the Game of Cycles on an n-cycle with at least one move played can be represented by a reduced canonical gamestate.

Proof: (Sketch) Since there is at least one move played, there will always be at least one gap. The order of the gaps doesn't matter so it can be arranged as a gamestate. Ever gamestate has a unique reduced canonical gamestate.
